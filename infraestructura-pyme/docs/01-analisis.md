# Análisis de Requisitos

## Cliente
- Empresa con sede central y 2 delegaciones
- ~250 usuarios

## Requisitos principales
- Conectividad entre sedes con redundancia
- VPN para acceso remoto
- Separación por VLANs (Administración, TI, Invitados)
- Firewall perimetral
- Monitorización con alertas

## Restricciones
- Presupuesto limitado (no renovar servidores)
- Plazo: 12 semanas
- Debe tener Documentación
